# Geist Serif

The variable Geist Serif (version 1.002), unmodified, from Vercel's [`geist`](https://www.npmjs.com/package/geist) 1.9.1 package
(`dist/fonts/geist-serif/GeistSerifVF.woff2`). Fontsource doesn't publish it, and `geist`
only serves Next.js, so it ships here. Licensed under the SIL Open Font License 1.1, in
`LICENSE.txt`.

One weight (400), upright only. Its one axis, `ELSH`, shapes the dots on letters and
punctuation: the regular dots at 0 (the default), squares at 25, triangles at 50, hearts at
100, the font's named instances.
